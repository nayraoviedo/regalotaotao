# Tutorial de bienvenida

Dibujos del tutorial (ver `lib/screens/tutorial/tutorial_screen.dart`).
Todos son PNG con fondo transparente y se pueden reemplazar con el mismo nombre.

- `guia_naranja.png`, `guia_blanco.png`: los gatitos que hablan (cuadrados, 600×600).
- `<clave>.png`: la ilustración de arriba de cada página. Claves:
  `bienvenida`, `inicio`, `animo`, `pomodoro`, `pregunta`, `notas`,
  `nosotros`, `casita`, `widget`, `listo`.
  Si no existe, se usa un dibujo que ya tiene la app.
